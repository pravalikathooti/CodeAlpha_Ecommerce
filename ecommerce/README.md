# CodeAlpha E-Commerce Website

A full-stack e-commerce website developed as part of the CodeAlpha Full Stack Development Internship.

## 📌 Project Overview

This project is a Django-based e-commerce web application that allows users to browse products, search and filter products, manage their shopping cart, place orders, and view their order history.

## 🚀 Features

- User Registration
- User Login and Logout
- Product Listing
- Product Details
- Product Search
- Product Categories
- Stock Availability
- Add Products to Cart
- Increase/Decrease Cart Quantity
- Remove Products from Cart
- Checkout
- Order Placement
- Order Success Page
- My Orders
- Django Admin Panel
- Responsive and user-friendly interface

## 🛠️ Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript
- SQLite
- Bootstrap
