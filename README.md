# 🛒 E-Commerce Website

A full-stack **E-Commerce Website** built using **Django** and **Python**.
The project provides a simple and user-friendly platform where users can browse products, manage their shopping cart, place orders, and view their order history.

## 🚀 Features

* 🏠 Home page displaying available products
* 📦 Product listing with product details
* 🗂️ Product categories
* 🛒 Add products to cart
* ➕ Increase product quantity
* ➖ Decrease product quantity
* ❌ Remove products from cart
* 💰 Automatic cart total calculation
* 👤 User registration
* 🔐 User login and logout
* 💳 Checkout system
* ✅ Order confirmation page
* 📋 My Orders page
* 🖼️ Product images
* 📊 Product stock management
* 🛠️ Django Admin panel for managing products and orders

## 🛠️ Technologies Used

* **Python**
* **Django**
* **HTML**
* **CSS**
* **SQLite**
* **Django Templates**
* **Django Authentication**

## ⚙️ Installation and Setup

### 1. Clone the repository


git clone <your-github-repository-link>


### 2. Open the project folder


cd ecommerce-store


### 3. Install Django


pip install django


### 4. Apply migrations


python manage.py migrate


### 5. Start the development server


python manage.py runserver


### 6. Open the website

Visit:


http://127.0.0.1:8000/


## 🛍️ Main Functionalities

### Product Management

Users can browse available products, view product information, and check product prices and stock.

### Shopping Cart

Users can add products to their cart and modify quantities or remove items before checkout.

### User Authentication

Users can create an account, log in, and securely access features such as checkout and order history.

### Checkout

Users can review their cart and place an order through the checkout process.

### Order Management

After placing an order, users can view their previous orders through the **My Orders** section.

### Admin Panel

The Django admin panel allows administrators to manage products, categories, stock, orders, and other application data.
